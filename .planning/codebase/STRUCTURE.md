## Directory Purposes

**`src/guardrails/`:**

- Purpose: Implements pre-inference and post-inference filters.
- Contains: Injection detection, topic enforcement, PII masking, and ADK plugins.
- Key files: `src/guardrails/input_guardrails.py`, `src/guardrails/output_guardrails.py`.

**`src/assignment/`:**

- Purpose: Checkpoint 3 production defense pipeline assembly and observability.
- Contains: Rate limiting, forensic audit logging, metric alerting, and egress control.
- Key files: `src/assignment/pipeline.py`, `src/assignment/rate_limiter.py`, `src/assignment/audit_log.py`, `src/assignment/monitoring.py`.

**`src/agents/`:**

- Purpose: Agent instantiation, prompt configuration, and security boundary shims.
- Key files: `src/agents/agent.py`, `src/agents/guards_agent.py`.

**`src/attacks/`:**

- Purpose: Checkpoint 4 red team attack orchestration and leak validation.
- Key files: `src/attacks/attacks.py`.

**`tests/`:**

- Purpose: Test automation split into smoke checks (starter repo baseline) and public contract checks (validation of student implementation).
- Key files: `tests/smoke/test_repo_structure.py`, `tests/public/test_lab_contracts.py`.

## Key File Locations

**Entry Points:**

- `src/main.py`: Unified CLI runner for Checkpoints 2, 3, and 4.
- `scripts/grade.py`: Submission verification and grade report generator.

**Configuration:**

- `src/core/config.py`: Environment variable loading, provider mapping, and secret loading.
- `pytest.ini`: Test discovery settings and path configurations.
- `.env.example`: Credentials template.

**Core Defense Logic:**

- `src/assignment/pipeline.py`: Defense-in-depth pipeline connecting all guardrails.
- `src/guardrails/input_guardrails.py`: Input injection and topic filters.
- `src/guardrails/output_guardrails.py`: Output secret redaction and content filters.

## Naming Conventions

**Files:**

- Snake-case for Python modules: `input_guardrails.py`, `rate_limiter.py`.
- Uppercase Markdown for project documentation: `CHECKPOINTS.md`, `RUBRIC.md`.

**Classes & Functions:**

- PascalCase for classes: `InputGuardrailPlugin`, `RateLimitPlugin`, `AuditLogPlugin`.
- snake_case for functions: `detect_injection`, `topic_filter`, `is_egress_allowed`.
- Test functions prefixed with `test_`: `test_detect_injection_basic`.

## Where to Add New Code

**New Guardrail Logic:**

- Input sanitization & injection detectors: `src/guardrails/input_guardrails.py`.
- Output redaction patterns: `src/guardrails/output_guardrails.py`.

**Pipeline & Policy Modifications:**

- Egress network policies: `src/assignment/pipeline.py:is_egress_allowed`.
- Pipeline plugin orchestration: `src/assignment/pipeline.py:build_production_plugins`.

**Adversarial Attack Payloads:**

- Red team prompts and variations: `src/attacks/attacks.py:ADVERSARIAL_PROMPTS`.
